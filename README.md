# Attention-Mechanisms-in-Advanced-YOLO-Architectures-for-Landslide-Detection
This study presents a systematic benchmark of three state-of- the-art object detection models, namely YOLOv11, YOLOv12, and YOLOv13, and evaluated on publicly available Bijie landslide datasets. To enhance feature repre- sentation, each baseline model is integrated with ten discrete attention mechanisms.
